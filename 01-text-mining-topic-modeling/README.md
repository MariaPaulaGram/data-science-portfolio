# Text Mining & Topic Modeling

## Análisis de producción científica argentina sobre Sociología

Este proyecto forma parte de mi formación en Data Science y presenta un análisis exploratorio y textual de un corpus de publicaciones científicas argentinas sobre Sociología.

## Objetivo

Analizar el corpus para identificar patrones de frecuencia, relaciones entre términos y estructuras temáticas presentes en las publicaciones.

## Datos

Los datos bibliográficos fueron obtenidos desde OpenAlex mediante consultas realizadas con R.

## Tecnologías

- R
- Tidyverse
- Tidytext
- Quanteda
- Igraph
- Ggraph
- DataExplorer

## Técnicas utilizadas

- Exploración de datos
- Análisis de valores perdidos
- Limpieza y normalización de texto
- Tokenización
- Stopwords
- Stemming
- Frecuencia de términos
- TF-IDF
- Matrices documento-término
- Redes de co-ocurrencia
- Análisis de comunidades
- Topic Modeling con LDA
- Análisis temporal de tópicos

## Resultados

El proyecto incluye visualizaciones para explorar la estructura del corpus, las relaciones entre términos y la evolución de los tópicos a través del tiempo.
